# 🎥 NoteTube

### Code, Math & Knowledge Synthesizer

> **Turn YouTube videos into structured knowledge, useful summaries, and
> in-depth concepts.**

NoteTube is an AI-powered learning application that transforms
educational YouTube videos into **organized summaries, detailed notes,
key concepts, and deeper explanations**.

It is designed for students, developers, researchers, and self-learners
who want to understand and retain knowledge from long-form video content
without manually taking notes throughout the entire video.

------------------------------------------------------------------------

## ✨ Features

### 🤖 AI-Powered Notes

Transform YouTube videos into useful, structured learning material using
AI.

-   Automatic content analysis
-   Intelligent summaries
-   Important information extraction
-   Structured learning notes
-   Key concept identification
-   Easy-to-understand explanations

### 🧠 Deep Synthesis

NoteTube goes beyond a basic summary with **Deep Synthesis**.

Deep Synthesis focuses on understanding the underlying concepts of a
video and presenting them in a detailed, meaningful way.

``` text
YouTube Video
      ↓
Content Analysis
      ↓
Key Ideas
      ↓
Concept Extraction
      ↓
Deep Explanation
      ↓
Structured Knowledge
```

### ☁️ Online AI Mode

NoteTube provides an **Online AI Mode** for cloud-based AI processing.

The current interface is designed around **Gemini 3.5 Flash cloud
intelligence**, allowing video content to be processed into AI-generated
learning material.

### 📥 Offline Notes

Generated syntheses can be saved for later access, allowing users to
build a personal knowledge library and revisit previously generated
content.

### 🎥 YouTube Video Support

Generate notes by providing:

-   YouTube URL
-   YouTube Video ID

### 🎯 Focused Synthesis

Users can optionally provide a **transcript or focus topic** to guide
the synthesis toward a specific subject or section.

``` text
YouTube Video + Focus Topic
            ↓
     Focused AI Synthesis
            ↓
       Relevant Notes
```

# 🧠 The Idea Behind NoteTube

Traditional YouTube learning often looks like:

``` text
Watch → Pause → Write Notes → Organize → Rewatch → Review
```

NoteTube simplifies the process:

``` text
YouTube Video → NoteTube → AI Synthesis → Structured Knowledge
```

The goal is not simply to make videos shorter.

The goal is to make the **knowledge inside those videos easier to
understand, organize, and revisit**.

# 📲 Installation & Platform Support (Android & iOS)

NoteTube supports direct installation on **both Android and iOS devices**:

### 🤖 Android Installation (Direct APK)
1. **Download the APK**:
   - Download **`NoteTube.apk`** from the **[Releases](../../releases)** section of this repository or from the project root.
2. **Install on your Android Phone**:
   - Open the downloaded file in your notification bar or File Manager.
   - If prompted by Android, enable **"Allow from this source"** for your browser or file manager.
   - Tap **Install** and launch NoteTube.

### 🍏 iOS Installation (iPhone & iPad via PWA / Web Clip)
Because iOS requires Apple Developer Program code-signing ($99/year) and macOS Xcode for raw `.ipa` distribution, NoteTube is configured to install directly onto iPhones and iPads via the Safari Web App engine:
1. Open the shared app URL in **Safari** on your iPhone or iPad:
   ```
   https://ais-pre-4ls7ti7utnddfhabos4bae-626794315083.asia-east1.run.app
   ```
2. Tap the **Share** button (the square with the arrow pointing up) at the bottom of Safari.
3. Scroll down and tap **"Add to Home Screen"** (`+`).
4. Tap **Add** in the top-right corner.
5. NoteTube will appear directly on your iOS Home Screen with its custom Apple-style app icon, running in full-screen standalone mode without Safari browser toolbars.

# 🛠️ Technology Stack

``` text
Mobile UI / Framework → Jetpack Compose (Material Design 3 + Apple HIG styling)
Language              → Kotlin 2.0 (Coroutines, Flow, StateFlow)
AI Engine             → Google Gemini 3.5 Flash API (Cloud Intelligence)
Offline Synthesizer   → On-Device Domain Knowledge Engine (Regex + Pattern Parser)
Local Persistence     → Android Room Database (SQLite Engine)
Networking            → OkHttp3 + Kotlinx Serialization
Image Loading         → Coil 2.6 (AsyncImage)
Build System          → Gradle (Kotlin DSL, Version Catalog)
```

# ⚙️ Building From Source

## 1. Clone the Repository

``` bash
git clone https://github.com/YOUR_USERNAME/NoteTube.git
cd NoteTube
```

## 2. Build the Android APK Locally

``` bash
./gradlew assembleDebug
```
The compiled APK will be generated at:
```
app/build/outputs/apk/debug/app-debug.apk
```

## 3. Automated Cloud Builds (GitHub Actions)
Every commit or version tag pushed to GitHub automatically triggers `.github/workflows/build-apk.yml`, generating a fresh `.apk` under the GitHub Actions **Artifacts** tab or GitHub Releases.

# 🔐 Security

NoteTube may communicate with external AI services depending on the
selected processing mode.

For development and deployment:

-   Keep API keys private
-   Use environment variables
-   Never hard-code secrets
-   Add `.env` to `.gitignore`
-   Use secure API communication
-   Protect backend credentials

Example:

``` gitignore
.env
.env.*
*.key
*.secret
```
